# NiK Smart Count — Construction

این مجموعه شامل نسخهٔ مرتب برای نصب تازه، سورس بخش‌های ساخته‌شده، فایل اجرایی کامل حسابداری و لوگوهای جدید است. برای نصب روی هاست تازه از `UPLOAD_NEW_HOST.zip` استفاده کن. این فایل برای جایگزینی مستقیم روی سایت دارای معلومات نیست؛ تنظیمات و کلید نصب تازه دارد.

## فایل‌ها

- `UPLOAD_NEW_HOST.zip`: فقط فایل‌های لازم هاست؛ بدون تست، گزارش، پچ‌های قبلی، فایل‌های تشخیص و بسته‌های تکراری.
- `SOURCE_COMPLETE.zip`: سورس بخش‌های PHP و مدیریت، سورس JavaScript بخش‌های تازه، CSS و فایل اجرایی حسابداری؛ با دستور ساخت.
- `BRANDING.zip`: لوگوی کامل شفاف، نشان بدون نوشته و اندازه‌های آمادهٔ تب و نصب.
- `INSTALL_KEY.txt`: کلید نصب همین بسته؛ خارج از پوشهٔ وب نگهداری کن.
- `QA_REPORT.txt`: نتیجه و حدود آزمایش‌ها.

## نصب تازه روی ProFreeHost

۱. یک حساب هاست و دامنه/ساب‌دامنه بساز. HTTPS با گواهی معتبر را فعال کن؛ ساخت مدیر و نصب برنامه روی دستگاه به HTTPS نیاز دارد.
۲. در پنل، دیتابیس MySQL بساز. نام سرور دیتابیس، نام کامل دیتابیس، یوزر کامل و رمز را از همان پنل بردار. نام سرور معمولاً با localhost فرق دارد؛ مقدار پنل را عیناً وارد کن.
۳. فایل `UPLOAD_NEW_HOST.zip` را در کمپیوتر باز کن. محتوای داخل آن را در پوشهٔ وب دامنه، معمولاً `htdocs`، آپلود کن. اگر مدیر فایل اجازهٔ Extract بدهد، می‌توان ZIP را همان‌جا استخراج کرد. فایل‌ها نباید داخل `htdocs/public_html` یا یک پوشهٔ اضافی باشند.
۴. فایل‌های نقطه‌دار مانند `.htaccess` و `api/.secrets/.htaccess` هم باید منتقل شوند. فایل `nsc-accounting-r3.js.gz` را جداگانه استخراج نکن.
۵. آدرس `https://YOUR-DOMAIN/installer.php` را باز کن. کلید را از `INSTALL_KEY.txt` وارد کن. مشخصات MySQL پنل همان هاست را بنویس؛ پورت معمولاً 3306 است، مگر پنل مقدار دیگری بدهد.
۶. «آزمایش اتصال»، سپس «ذخیرهٔ اتصال» را بزن.
۷. در قسمت دوم، نام کاربری مدیر، نام شرکت و رمز حداقل ۱۲ حرف را تعیین کن؛ «تکمیل نصب و ساخت مدیر» را بزن. رمز آماده یا مشترک همراه بسته نیست.
۸. ورود مدیر: `https://YOUR-DOMAIN/office7-login.php`
۹. ورود مالک و کارمندان: `https://YOUR-DOMAIN/login.php`
۱۰. در دفتر هفت مالک بساز. برای اجازهٔ ساخت کارمند، حد مجاز کارمند مالک و خدمت «کاربران» را فعال کن. مالک از «مدیریت کارمندان» حساب‌ها و صلاحیت‌های کارمندان را تعیین می‌کند.
۱۱. در دو دستگاه با یک حساب آزمایشی وارد شو، یک پروژه و مصرف آزمایشی بساز، صفحه را دوباره باز کن و مبلغ را در دستگاه دوم مقایسه کن. تا این بررسی روی هاست واقعی موفق نشده، انتقال حساب‌های اصلی را تکمیل‌شده حساب نکن.

نیازهای برنامه: PHP 8.1 یا بالاتر، PDO MySQL، MySQL/MariaDB با InnoDB، HTTPS، JavaScript مرورگر به‌روز و دسترسی نوشتن PHP در `api/.secrets` و `uploads`. Node و npm روی هاست لازم نیستند. کارکرد GET_LOCK، امکان ساخت جدول و مجوزهای حساب MySQL باید توسط هاست فراهم شوند.

ProFreeHost برای فایل‌ها و منابع محدودیت دارد. فایل‌های این تحویل از سقف اعلام‌شدهٔ ۱۰ مگابایت برای هر فایل کوچک‌تر هستند. نصب و عملکرد نهایی روی حساب ProFreeHost شما هنوز آزمایش نشده است.
منابع رسمی: https://profreehost.com/features/ و https://profreehost.com/support/fair-usage-limits

## لوگو و نصب روی دستگاه

- تب مرورگر: نشان بدون هیچ نوشته، در اندازه‌های 16 و 32 پیکسل.
- صفحهٔ برنامه و برند: لوگوی کامل شفاف، بهینه‌شده برای وب.
- آیکن نصب: لوگوی کامل با تمام نوشته‌ها در PNGهای 192 و 512 پیکسل؛ آیکن 180 پیکسل برای iPhone/iPad.
- Android/Chrome/کمپیوتر: از منوی مرورگر Install app یا Add to home screen را انتخاب کن؛ ظاهر گزینه به مرورگر بستگی دارد.
- iPhone: Safari → Share → Add to Home Screen.
- این نسخه PWA است، فایل APK یا EXE نیست. برای دریافت حساب و ثبت مرکزی، اینترنت لازم است. سرویس‌ورکر API و صفحات را آفلاین کش نمی‌کند.
- اگر آیکن نصب‌شدهٔ قبلی هنوز قدیمی بود، پس از اطمینان از ثبت معلومات، میانبر قدیمی را حذف و از همین دامنه دوباره اضافه کن. Local Storage و معلومات سایت را پاک نکن.

## سورس و ساخت

در سورس، `web` محتوای هاست است؛ `portal` فایل‌های خوانای مدیریت/ورود/ثبت مرکزی است. `accounting-client.js` فایل کامل اجراییِ کامپایل‌شدهٔ حسابداری است. سورس اصلی React/TypeScript پروژه به من داده نشده بود؛ بنابراین نمی‌توان آن را سورس اصلی React بازسازی‌شده نامید. بخش‌های داخلی همین فایل اجرایی را بدون داشتن سورس اصلی نمی‌توان با اطمینان به‌طور کامل از کد بلااستفاده پاک کرد؛ به همین دلیل نگهداری شده است.

برای ساخت، داخل پوشهٔ سورس با Node 22+ اجرا کن:

    npm install
    npm run build

ساخت، صفحه‌های مستقل PHP و فایل فشردهٔ حسابداری را می‌سازد و کلید نصب تازه در `web/api/.secrets/install.key` ایجاد می‌کند. این فرمان را روی فایل‌های سایت نصب‌شده یا پوشهٔ دارای کلیدهای تولیدی اجرا نکن.

## وضعیت ذخیره و انتقال معلومات

روی نسخهٔ محلی، ثبت در MySQL، بازیابی پس از رفرش، دریافت در مرورگر دوم و محدودیت دسترسی آزمایش می‌شود. خطای ذخیره روی هاست فعلی nik-smartcount.com هنوز از روی پاسخ درخواست ناموفقِ همان حساب تشخیص قطعی نشده است؛ این تحویل ادعای رفع قطعی آن روی هاست فعلی را نمی‌کند. پیام خطا اکنون کد HTTP و پاسخ خطا را در موارد قابل دریافت دقیق‌تر نمایش می‌دهد.

نصب در دامنهٔ تازه به‌صورت خودکار معلومات سرور قبلی یا تغییرات ثبت‌نشدهٔ مرورگر قبلی را منتقل نمی‌کند. دیتابیس تازه، معلومات مستقل دارد. قبل از انتقال واقعی، از دیتابیس قبلی، uploads و تغییرات ثبت‌نشده بکاپ بگیر؛ فقط بعد از تأیید ثبت و مقایسهٔ معلومات، سرویس قبلی را کنار بگذار.

فایل‌ها و حساب‌های قبلی گوگل درایوت حذف نشده‌اند. پاک‌سازی در همین بستهٔ جدید انجام شده است.
