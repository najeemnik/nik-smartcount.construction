# استقرار روی هاست فری / اشتراکی

این راهنما برای هاست‌هایی است که **PHP + MySQL + Apache** دارند (فری‌هاست‌های
cPanel/Byet). روی Netlify، Vercel، GitHub Pages و Cloudflare Pages **کار نمی‌کند** —
آن‌ها PHP اجرا نمی‌کنند.

## پیش‌نیازها

| مورد | حداقل | چرا |
|---|---|---|
| PHP | ۷.۴ (توصیه ۸.۲+) | `pdo_mysql`، `mbstring`، `json`، `openssl`، `zlib` |
| MySQL / MariaDB | ۵.۷+ | همهٔ دادهٔ برنامه |
| Apache + `.htaccess` | — | هدرهای امنیتی، CSP، جلوگیری از دسترسی به `.secrets` |
| قابل‌نوشتن | `api/.secrets/` و `uploads/` | ذخیرهٔ پیکربندی دیتابیس و فایل‌های کاربر |

اگر هاست‌ت `php_value` در `.htaccess` را بلاک می‌کند مشکلی نیست — این پروژه از آن استفاده نمی‌کند.

---

## ۱) ساخت بسته

```bash
./tools/make-deploy-package.sh
```

خروجی: `deploy-out/nik-smartcount-<تاریخ>.zip`

بسته **عمداً** شامل این‌ها نیست: `tests/`، `review/`، `tools/`، `docs/`، `.git` و
`api/.secrets/database.php` (رمز دیتابیس هرگز بسته‌بندی نمی‌شود). اسکریپت پیش از
ساخت zip بررسی می‌کند که هیچ `*.key` یا `database.php` داخل بسته نباشد.

---

## ۲) ساخت دیتابیس

در پنل هاست → **MySQL Databases** → یک دیتابیس و یک کاربر بساز و کاربر را به دیتابیس
اضافه کن (با دسترسی کامل). این چهار مقدار را بردار:

```
Host:     sqlXXX.<host>.com      ← هرگز localhost نیست در فری‌هاست‌ها
Database: if0_12345678_nik
User:     if0_12345678
Password: ...
```

---

## ۳) آپلود

1. پنل → **File Manager** → وارد `htdocs` (یا `public_html`) شو
2. فایل zip را آپلود کن → روی آن **Extract** بزن
3. مطمئن شو `index.php` مستقیم داخل `htdocs` است، نه داخل یک پوشهٔ اضافه
4. دسترسی پوشه‌ها:
   - `api/.secrets` → `755`
   - `uploads` → `755`

---

## ۴) ساخت کلید نصب

نصب بدون کلید رد می‌شود (`api/setup.php` آن را از `api/.secrets/install.key` می‌خواند).
اگر SSH داری:

```bash
php tools/nsc-init.php
```

اگر نداری (حالت معمول فری‌هاست): در File Manager داخل `api/.secrets/` یک فایل به نام
`install.key` بساز و داخلش یک رشتهٔ تصادفی ۳۲+ کاراکتری بگذار، مثلاً:

```
8f3c1d9a7b2e5046c8a1f0d3e6b94a72
```

> این کلید فقط برای «یک‌بار نصب» است. بعد از پایان نصب می‌توانی فایلش را پاک کنی.

---

## ۵) اجرای نصب

`https://<دامنهٔ تو>/installer.php` را باز کن:

1. همان کلید را در فیلد **کلید نصب** بگذار
2. چهار مقدار دیتابیس مرحلهٔ ۲ را وارد کن → **تست اتصال**
3. **ذخیره** → فایل `api/.secrets/database.php` ساخته می‌شود
4. بعد از این مرحله، **`install.key` را پاک کن** تا کسی نتواند دوباره نصب کند

سپس `/login.php` را باز کن و حساب مدیر را بساز.

---

## ۶) بررسی بعد از نصب

| چه چیزی | کجا | انتظار |
|---|---|---|
| سلامت کل سیستم | `/api/health.php` | `success: true` و `data.ok: true` |
| نسخهٔ ساختار | همان پاسخ | `2026-10-29.1` |
| جدول مشتریان | `/api/health.php` یا phpMyAdmin | جدول `clients` موجود |
| حساب معلق | phpMyAdmin | `SELECT * FROM chart_of_accounts WHERE account_code='8200'` |
| داشبورد | `/workspace.php` | بدون خطای ۵۰۰ |
| تأمین‌کننده | جزئیات یک تأمین‌کننده | تاریخچهٔ پرداخت باز می‌شود |

اگر `schema.error` در `api/.secrets/` دیدی یعنی ارتقای خودکار ساختار شکست خورده —
معمولاً چون کاربر دیتابیس اجازهٔ `CREATE` ندارد. در آن حالت `schema.sql` را دستی از
phpMyAdmin اجرا کن.

---

## ۷) نکات امنیتی بعد از استقرار

- `install.key` و `installer.php` را پاک/غیرفعال کن
- رمز پیش‌فرض نداری، ولی حتماً رمز مدیر را قوی بگذار
- HTTPS را از پنل فعال کن؛ ورود بدون HTTPS کار نمی‌کند (`crypto.subtle`)
- هیچ‌وقت `api/.secrets/` را با کسی به اشتراک نگذار

---

## محدودیت‌های فری‌هاست که ممکن است به آن بربخوری

| علامت | علت | راه‌حل |
|---|---|---|
| خطای ۵۰۰ روی کل سایت | نسخهٔ PHP قدیمی (< ۷.۴) | از پنل نسخه را عوض کن |
| ۵۰۰ فقط در بعضی صفحات | افزونهٔ `mbstring` یا `pdo_mysql` خاموش | در پنل فعالش کن |
| حلقهٔ ریدایرکت | HTTPS فعال نیست ولی `.htaccess` اجبار می‌کند | چهار خط `RewriteCond/RewriteRule` را کامنت کن |
| «اتصال برقرار نشد» در نصب | Host را `localhost` گذاشتی | مقدار `sqlXXX.…` پنل را بگذار |
| ارتقا هر بار تکرار می‌شود | کاربر دیتابیس اجازهٔ DDL ندارد | `schema.sql` را دستی اجرا کن |
| سرویس‌ورکر خطا می‌دهد | سایت روی HTTP است | HTTPS را فعال کن |
