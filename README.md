# NiK Smart Count

PHP/Apache construction accounting application. This snapshot includes the latest reviewed financial, permissions, recovery, responsive layout, compact navigation, About page, original developer logo, theme synchronization and refined controls changes from the November 2026 update packages.

## Start here

- **[DEVELOPMENT.md](DEVELOPMENT.md):** architecture, editing and setup notes for developers and coding assistants.
- **[AGENTS.md](AGENTS.md):** project-specific instructions for safe changes.
- **[.checks/README.md](.checks/README.md):** isolated functional/security test procedures.
- **[MENU_ABOUT_REVIEW_FA.md](MENU_ABOUT_REVIEW_FA.md):** compact navigation and About page review.
- **[SYSTEM_AUDIT_FA.md](SYSTEM_AUDIT_FA.md):** accounting/security findings and testing limits.

This repository contains application code, example configuration and schema—not your hosted company's database, uploads, credentials or private server configuration. Back up the hosting files and database separately before deployment.

The original React/TypeScript project is not present. The current compiled browser module and targeted source adapters are included; do not mistake this checkout for an original Vite/React source tree.
